# Bar Ops v0.11.0 — Employee Self-Service Foundation

Built from v0.10.11.

## Added

- Unified manager Requests workspace for time off, open-shift claims, and employee-approved handovers/swaps.
- Manager approve/reject actions using the existing transactional APIs.
- In-app notifications for every major self-service handoff and decision.
- Direct notification links into the manager Requests workspace and employee request/schedule pages.
- Server-side validation for employee time-off requests.
- Focused v0.11.0 regression coverage and self-service audit report.

## Preserved

- Existing shift locking and concurrency protections.
- Existing employee portal design and navigation.
- Existing schema; no migration is required.
