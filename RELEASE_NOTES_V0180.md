# Bar Ops v0.18.0 — Stable Interface Recovery

v0.18.0 abandons the broken v0.17.0 presentation architecture and restores v0.10.6 as the complete working UI baseline. This is a controlled rollback, not another CSS patch.

### Included
- coherent fixed application shell
- established owner and employee layouts
- compact monochrome design system
- installable PWA foundation
- PostgreSQL-backed application foundation present in v0.10.6
- rotated v0.18.0 service-worker cache

### Explicitly excluded
- all later cascade reconstruction layers
- floating-navigation experiments introduced after v0.10.6
- duplicated reset/override styles from v0.11.0–v0.17.0
