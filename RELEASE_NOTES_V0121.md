# Bar Ops v0.12.1 — Schedule Conflict Resolution UX

Built from v0.12.0.

## Changes
- Added a conflict-only schedule view for overlapping and availability conflicts.
- Added an accessible conflict review toggle with a live conflict count.
- Added a clear empty state when the selected period has no conflicts.
- Availability-conflicted shifts now explain the reason in the edit dialog.
- The edit dialog guides managers to reassign, change the time, or convert the shift to an open shift.
- Conflict publishing safeguards from v0.12.0 remain unchanged.

No database migration is required.
