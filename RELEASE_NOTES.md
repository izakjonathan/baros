# Bar Ops v0.11.6 — Compact Floating Menu

The oversized floating navigation panel has been replaced with a compact expanding pill that matches the supplied reference direction.

- Collapsed state is a black circular button with a white menu icon.
- Expanded state keeps the black circle anchored and changes the icon to X.
- A slim white menu strip expands horizontally to the right.
- Workspace titles are displayed in one compact row.
- Overflowing destinations scroll horizontally inside the strip.
- The menu stays open while navigating and only closes from the black toggle.
- The profile block and tall popover layout were removed.
