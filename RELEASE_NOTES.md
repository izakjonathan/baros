# Bar Ops v0.12.2 — Interface Refinement & Layout Stability

This release corrects the visual and layout issues identified in the v0.12.1 mobile screenshots.

## Highlights
- Stable location-name fallback prevents intermittent “No active location” labels after a workspace has resolved.
- One canonical late-stage design layer replaces accumulated release-specific overrides.
- Compact fixed header and page rhythm across all manager and employee views.
- Scroll-safe dialogs with sticky action footers and compact two-column shift times.
- Tighter Team and payroll cards.
- Orders tables scroll horizontally instead of clipping or compressing columns.
- Floating navigation is constrained to the safe viewport and hidden while dialogs are open.
- Shared typography, spacing, forms, cards and controls remain token-driven.

No database migration is required.
